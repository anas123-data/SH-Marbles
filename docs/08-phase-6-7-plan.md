# Phases 6–7 — Collection and Stone Library

## Creative and content decisions

Continue the established ivory/charcoal editorial identity. Collections use asymmetrical image-led introductions; product pages give the object and its details room; the Stone Library uses close surface studies and a restrained comparison interface. Use existing local fonts, CSS motion and Next images. No new dependency is required.

The owner has authorized proceeding with provisional content and will provide a confirmed catalogue later. Descriptive product names are editorial labels, not official model names. Material names describe visible colour and pattern only. Origin, trade names, dimensions, finish specifications, suitability, availability, fabrication and shipping remain explicitly unconfirmed. Product imagery is supplied imagery with unconfirmed photographic/render provenance. Public repository publication of the supplied images was approved separately; this does not verify product specifications.

## Journeys and routes

- Home → `/collections` → `/collections/[category]` → `/products/[slug]` → contextual project brief.
- Home → `/stone-library` → search/tone/pattern filters → `/stone-library/[slug]` → material brief.
- Stone Library → select two or three studies → accessible comparison dialog → save material preferences in a project brief.
- Product → related visual material direction → stone study; no implied material compatibility.

Shared header, footer, breadcrumbs and draft provider apply to all routes. Preserve homepage sections and existing local brief copy/download behaviour. A real inquiry service and configurator remain later phases.

## Engineering and acceptance

Typed local catalogue behind a read repository; null means unknown. Route metadata and static parameters; invalid categories/slugs return 404. Product/offer schema is deliberately omitted for unverified editorial records. Preview indexing stays disabled pending production facts/domain. Filters announce result counts and include a reset/empty state. Galleries and dialogs work with keyboard and reduced motion. Comparison is temporary browser state, not a saved submission.
